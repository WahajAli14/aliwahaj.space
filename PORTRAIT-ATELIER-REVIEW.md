# Portrait atelier revision

5 November 2026. Latest visual revision; supersedes the navy/periwinkle appearance in INTERACTION-AND-3D-REVIEW.md. Branch/local preview only, no production deployment.

## Design

The user rejected the dashboard-like dark theme. The opening now centers Ali's identity: an oversized name, an asymmetric photographic object and direct work/résumé actions. Fixed mineral background (#eeeaf0), wine text (#351e32), rose accent (#9e2857), quiet porcelain surfaces (#faf8fb), and three muted project tabs replace the observatory styling. There is no appearance switch. Bricolage Grotesque carries the name, with Geist for body reading. The request replay now sits inside backend reasoning rather than competing with personal identity in the hero.

The portrait is the user-authorized front-facing suit photo from Downloads. The matching profile was selected for future likeness checks. Six references were inspected locally; only the front-facing photo is included in the portfolio. The JPEG is 167,787 bytes and contains no EXIF marker. A small pointer-driven tilt adds dimension on fine pointers; it is disabled by reduced motion or the shared pause state. This photographic effect is not represented as a reconstructed face mesh.

The optional monogram viewer remains a real GLB, now with rose/wine materials. Case titles, index links and direct hashes still open native reasoning/evidence panels. Original PDF résumé access is preserved.

## Portrait generation

TRELLIS.2 is the preferred candidate for a first texture/mesh trial, not a verified winner for facial identity. Its official local prerequisites are Linux and NVIDIA with at least 24 GB memory: https://github.com/microsoft/TRELLIS.2. TripoSR is a lighter baseline with about 6 GB default VRAM: https://github.com/VAST-AI-Research/TripoSR. Neither has been run locally on this Mac.

The original official TRELLIS project links to a Microsoft Hugging Face Space that now redirects to trellis-community/TRELLIS. This is the older TRELLIS demo, not a confirmed TRELLIS.2 endpoint. The user subsequently approved that changed receiving account. The selected suit photo was uploaded and a GLB was generated and reviewed locally. Its eyes/mouth and profile were distorted, so it was rejected for portfolio use. A same-seed refinement at 24 sampling steps per stage returned generic service errors on the attempt and one retry. No portrait mesh was integrated. See 3D-TRIAL-REVIEW.md for the latest result.

## Review limits

The theme is a design proposal, and its uniqueness is not an objective benchmark. Recruiter task coverage is stronger than before: identity, role, current experience, case reasoning and résumé are directly available. Historical numeric design ratings do not constitute user acceptance of this revision.

No physical-device, cross-browser, screen-reader, enlarged-text, full automated accessibility or performance audit has been performed. The local explorer is keyword retrieval; the football implementation remains unverified. The model-viewer error/retry path was code-reviewed but not fault-injected. Production remains unchanged.
