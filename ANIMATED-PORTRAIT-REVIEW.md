# Animated illustrated portrait

5 November 2026. Draft branch/local preview only. This supersedes the static-photo opening described in PORTRAIT-ATELIER-REVIEW.md.

## Implemented

The clean illustrated bust is now the default hero image, clearly labeled Illustrated portrait. Illustration / Photo buttons retain immediate access to the original photo, update pressed state and descriptive alternative text, and work while motion is paused. The image frame reserves space for both modes.

The illustration floats only seven pixels over an eight-second cycle with a small ground-shadow change. Pointer-driven depth is capped at three degrees in either direction and uses at most one queued frame. Fine pointers only; no pointer tilt on touch. The hero now has a shared Pause motion button rather than requiring readers to open a case study to stop motion. Manual pause, reduced-motion preferences, page visibility and offscreen suspension are accounted for. Photo mode has no floating animation.

The hero WebP is 50,318 bytes at 900 × 823 pixels, with transparency preserved. It was encoded from the built-in image-generation output, without changing the illustration's composition. The original photo remains separate and loads when selected. The source prompt is saved locally in outputs/3d-portrait-v2/REFERENCE.md.

This is an animated raster illustration, not a reconstructed face mesh. The separately labeled Explore 3D mark action still opens the real monogram GLB. Microsoft TRELLIS.2 received the new reference with user approval; actual portrait mesh generation remains quota-blocked pending signed-in access. The rejected original-TRELLIS mesh was not reused.

## Verified

- HTML/local-file/fragment checks and all JavaScript syntax pass.
- Existing shared-motion regression tests pass, including reduced-motion scheduling, visibility, modal pause/restore and repeated toggling. These tests cover the shared scheduler/simulation, not the portrait's CSS timeline.
- Browser computed styles showed the portrait animation running; its transform changed over time. Pause changed its play state to paused. The original Photo mode had animation-name none.
- Enter selected Photo and Illustration, updating image source, alt text, caption and pressed state. Switching remained functional while paused.
- Desktop pointer interaction produced a small bounded rotateX/rotateY transform. Opening the 3D dialog paused portrait motion and cleared pointer tilt. After navigating into a case study, the portrait became offscreen and paused while the shared global motion state remained running.
- Browser layout checks at 320, 390, 768 and 1280 CSS pixels found no horizontal overflow. The two appearance buttons and pause control each measured at least 44 pixels high.
- No production deployment or merge.

## Limits

OS-level reduced-motion, physical-device, cross-browser and screen-reader checks were not performed. The CSS preference fallback and shared runtime preference behavior were source/harness reviewed. Lighthouse and field performance were not measured. The reference's stylistic resemblance is a design judgment, not a biometric accuracy score. A valid portrait GLB has not yet been generated by TRELLIS.2.
